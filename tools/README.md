# Herramientas
- `capturas.js` · capturas en 4 tamaños (+ movimiento reducido). `node tools/capturas.js ./capturas` con `python3 -m http.server 8765` corriendo.
- `zoom.js` · simula zoom del navegador 25 %–200 % y mide alineación de la portada.
- `video-bucle.sh` · crea el video de portada en bucle sin audio (ffmpeg).
- `construir-un-archivo.py` · genera la web en un solo HTML.
Requisitos: Node + Playwright, Python 3, ffmpeg.
